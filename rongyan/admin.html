⚙️ 首次设置

为保护你的 Token 安全，系统会将其加密存储在浏览器中。
每次使用管理后台需输入本地密码解锁。

  1. 联系管理员索要 GitHub Token
  2. 粘贴 Token 并设置一个本地解锁密码
  3. 后续每次打开只需输入密码即可
🛡️ 安全说明：
• Token 使用 AES-256 加密后存储，F12 无法直接查看
• 每次打开需输入密码解密，关闭页面后自动锁定
• 请创建最小权限 Token：只勾选 repo 权限
• 建议在 GitHub 设置 Token 过期时间为 90 天
